# Quick Start Guide

## Installation Steps

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Open your browser:
```
http://localhost:5173
```

## What You'll See

### Dashboard Overview
- **4 Statistics Cards**: Users, Revenue, Orders, Conversion Rate
- **Revenue Chart**: Monthly performance visualization
- **Activity Feed**: Real-time user activities with colored avatars
- **Quick Actions**: Fast access to common tasks
- **Top Products**: Best-selling items with trend indicators
- **Monthly Goals**: Progress tracking with visual bars
- **Sales by Region**: Geographic breakdown
- **Recent Customers**: Latest customer activity
- **Orders Table**: Comprehensive order management

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build

## Customization

### Colors
Edit `tailwind.config.js` to customize the color palette.

### Components
All components are in the `components/` directory and can be modified independently.

### Layout
- `App.tsx` - Main layout with sidebar and header
- `Dashboard.tsx` - Dashboard page with all widgets
